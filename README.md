# Money Transfer Service

#### `money-transfer-service` — это микросервис, предназначенный для управления денежными переводами между счетами. Он предоставляет REST API для создания, выполнения и отслеживания транзакций между пользователями, а также обеспечивает проверку доступного баланса, статус транзакции и историю переводов.

## Основные возможности

- **Создание транзакций** между счетами пользователей.
- **Проверка доступного баланса** отправителя перед выполнением транзакции.
- **Запись истории переводов** с указанием статусов операций.
- **Отмена транзакций** с соответствующей проверкой.
- **Аудит и логирование** действий пользователей.

## Технологии

Проект построен с использованием следующих технологий:

- **Java** (JDK 22)
- **Spring Boot** — для построения REST API
- **Spring Data JPA** — для работы с базой данных
- **PostgreSQL** — в качестве основной базы данных
- **Liquibase** — для управления миграциями базы данных
- **Lombok** — для упрощения кода
- **Docker** — для контейнеризации приложения
- **JUnit и Mockito** — для тестирования
